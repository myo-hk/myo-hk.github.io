## 1. 背景與目標

## 2. FAQ 問題清單

### 2.1 主頁 FAQ（6-8 條）

根據 SEO 研究，以下為準新人最常搜尋及關心的問題：

1. **證書套的尺寸是否適合香港婚姻登記處的 A4 結婚證書？**
   - 答：適合。我們的證書套專為香港 A4 結婚證書設計，內尺寸約 31cm × 22.5cm，完美容納標準證書，無需摺疊。另備有其他尺寸可選。

2. **可以在證書套上印製哪些文字？**
   - 答：可以印上新人名字（中英文均可）和結婚日期，採用熱轉印（燙印）工藝，呈現燙金或燙銀質感。設計師款更可加入指定字句。

3. **亞麻布和磨砂珠光材質有什麼分別？**
   - 答：亞麻布（米色）紋理自然質樸，手感溫暖，適合簡約風格；磨砂珠光（藍色）帶細緻光澤，更顯華麗。兩款均為硬殼封面，耐用防潮。

4. **訂製一個證書套需要多久時間？**
   - 答：一般訂製需時約 7-14 個工作天（視乎訂單量），確認設計稿後開始製作。如有急單可與我們聯絡協調。

5. **如何清潔和保養結婚證書套？**
   - 答：建議以乾軟布輕拭表面，避免接觸水份或化學溶劑。存放於陰涼乾燥處，避免陽光直射。詳見我們的證書套保養指南。

6. **證書套的價格是多少？**
   - 答：經典款 HK$388（亞麻布／磨砂珠光），設計師款 HK$588，價格已包含名字與日期印刷。詳情可參閱定價页面。

7. **訂購流程是怎樣的？**
   - 答：選擇款式與顏色 → 提供新人名字與結婚日期 → 我們確認設計稿 → 製作 → 送貨。全程可透過 Instagram 或 WhatsApp 溝通。

8. **可以只訂購一個證書套嗎？**
   - 答：可以。您可以按需要訂購一個或一對，沒有最低數量限制。

## 3. 頁面設計

### 3.1 主頁 FAQ 區塊（index.html）

**位置：** 在 `#contact` 區塊之前（即聯絡我們的上方），footer 之前。

**樣式：** 手風琴（accordion）摺疊式，點擊問題展開答案。
- 與現有配色一致（暖色系，#fdfaf6 背景，CD853F 主色）
- 標題「常見問題」使用 .section-title 樣式保持一致
- 每條問題點擊後平滑展開答案
- 答案結尾可加「了解更多 →」連結到 faq.html

**Schema:**
- 使用 FAQPage JSON-LD（即使 2026 年不再顯示 rich result，對 AI 引擎仍有幫助，且無害）

### 3.2 獨立 FAQ 頁面（faq.html）

**URL:** `https://myo-makeyourown.pages.dev/faq.html`

**設計：**
- 與主頁相同 navbar + footer
- 所有問題分類排列（產品、訂購、運送、售後）
- 使用 FAQPage Schema
- 每個分類使用 H2 標題

**SEO 配置：**
- `<title>`: My O! 常見問題 — 結婚證書套 FAQ | 香港
- `<meta name="description">`: 結婚證書套常見問題：尺寸、訂製、價格、運送等一站式解答。
- `<link rel="canonical">` 指向自身
- OG tags
- `<meta name="robots" content="index, follow">`
