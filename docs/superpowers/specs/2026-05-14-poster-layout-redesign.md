# 海報佈局重新設計規格

## 概述
將結婚證書套宣傳海報的產品特點區域重新排列，實現對角線佈局並整合顏色展示，節省垂直空間。

## 變更內容

### 1. 產品特點區域重構
- 將 `color-combo-section` 移入 `highlights-section` 內部
- 四個 `highlight-item` 採用對角線排列：
  - 左上：💖 完美尺寸
  - 右上：✨ 高質感封面
  - 右下：🛡️ 穩妥保護
  - 左下：🎨 精緻印刷
- 顏色圖片置於四個特點中央

### 2. 文字大小增加
- `highlight-item` 文字增加 40-50%
- `personalize-section` 文字增加 40-50%

### 3. 結構保持不變
- 精選款式維持在分隔線下方
- 底部 QR Code 區域維持不變
- 品牌區域維持可點擊返回首頁
