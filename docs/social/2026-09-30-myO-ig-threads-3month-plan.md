## 1. 執行摘要

### 目標

本計畫以「品牌認知 × SEO 導流」為雙核心目標，透過 12 週（3 個月）IG 與 Threads 雙平台內容輸出，達成以下狀態：

1. **品牌認知**：讓「MyO 專屬結婚證書套」成為香港新人搜尋「結婚證書套」時，首先出現的本地品牌。
2. **SEO 導流**：每月將 IG / Threads 的點擊轉化成 blog 瀏覽行為，推動 421 篇文章的有机流量。
3. **內容資產積累**：5–6 個 Highlights 成為新人瀏覽的第一站；8 支以上 Reels 成為可長期搜尋的資產。

### 為何這套節奏

- **M1 先基建**：bio 三段式、Highlights、置點貼文、UTM 追蹤同時到位，後續內容才有數據可回傳。
- **M2 放量**：每篇證書套相關文章拆成 IG 貼 + Threads 文字帖，內容生產與 blog 文章庫存同步，不需另找素材。
- **M3 收網**：支柱一（工藝與材質）比例拉高到 40%，配合限量/聯名 / KOL 協作，把品牌詞攻佔。

### 3 個月後的狀態

| 維度 | 目標數值 |
|------|---------|
| IG 貼文總數 | ≥ 48 篇（含 12–16 支 Reels） |
| Threads 帖數 | ≥ 180 則 |
| Highlights | 5–6 個（已命名、封面圖完成） |
| 新追蹤者（IG） | ≥ 300（冷啟動後自然增長） |
| IG 觸及（非粉絲）占總觸及比 | ≥ 50%（W12 觀察） |
| 每月 blog 流量來自社交媒體 | ≥ 3%（GA4 可查） |
| Threads 索引（Google） | ≥ 30 則被 Google 收錄 |

## 2. 前置必做事項（Day 0–3）

以下為 W1 開跑前必須完成的清單，未按序執行會導致後續內容無數據可觀測。

### 2.1 Threads 開通步驟

1. 以同一 Instagram 帳號登入 [threads.net](https://threads.net)（iOS/Android 或瀏覽器版）。
2. 系統自動導入 IG 頭像與姓名，**立即檢查**個人資料頁：姓名顯示為「MyO 專屬結婚證書套」。
3. 位置設為 Hong Kong。
4. 將 Instagram bio 中的 IG 連結（如有）替換為 Threads 網址。
5. 首帖：以粵語文字寫一段自我介紹，說明 MyO 是賣什麼的品牌，並附一張證書套成品圖。

> **注意**：Threads 對 Google 有索引機會（Google 已確認會爬取 Threads），因此 Threads 帖文需包含關鍵字「結婚證書套」、「燙印」、「亞麻布」等。

### 2.5 UTM 追蹤腳本規格

**背景**：目前網站沒有任何 `utm_source` 追蹤，社交媒體流量無法與 GA4 / PostHog 關聯。

**規格說明（不實作，僅描述）**：

#### 需要修改的檔案類型

| 檔案類型 | 數量 | 修改目的 |
|----------|------|---------|
| `blog/*.html` | 421 | 將文章底部的分享按鈕 URL 加入 UTM |
| 手機 Sticky Bar（注入模板） | 全站 | WhatsApp / IG 按鈕加入 UTM |
| `index.html` 社交圖標連結 | 1 | 首頁 WhatsApp / IG 連結加入 UTM |
| `v2.html` 社交圖標連結 | 1 | 同上 |
| 博客索引 `blog/index.html` | 1 | 分享按鈕連結加入 UTM |

#### 需加入的 query 參數

| 參數 | 值（範例） | 說明 |
|------|-----------|------|
| `utm_source` | `instagram` / `threads` | 來源平台 |
| `utm_medium` | `social` | 媒介類型 |
| `utm_campaign` | `myo-brand` | 活動名稱 |
| `utm_content` | `whatsapp_btn` / `ig_btn` / `sticky_bar` | 區分元素位置 |

#### 範例 URL（最終成品）

```
https://myo-makeyourown.pages.dev/blog/結婚證書套推薦.html?utm_source=instagram&utm_medium=social&utm_campaign=myo-brand&utm_content=whatsapp_btn
```

#### `--test` dry-run 驗證方式

腳本執行前，先運行 `--test` 模式，輸出符合以下格式的報告：

```
=== UTM Tracking Script (DRY-RUN) ===
Files scanned: 425
Links requiring modification: 1,247
Files that will be modified: 425
Sample diff (blog/結婚證書套推薦.html):
  - href="/blog/結婚證書套推薦.html"
  + href="/blog/結婚證書套推薦.html?utm_source=instagram&utm_medium=social&utm_campaign=myo-brand&utm_content=whatsapp_btn"
================================================
```

驗證要點：
1. 已存在 `utm_source` 參數的連結不重複加入。
2. 動態 URL（`window.location.href`）不處理，只處理靜態 `<a href>`。
3. 執行 `--test` 無錯誤後，再以裸執行（無 `--test`）寫入。

## 3. 內容支柱詳細定義

### 支柱一：工藝與材質拆解（30%）

| 項目 | 說明 |
|------|------|
| **定義** | 實物對比、開箱、燙印特寫、材質觸感解說 |
| **對應關鍵詞** | 結婚證書套推薦、證書套材質比較、燙印證書套價錢、亞麻布 vs 磨砂珠光 |
| **適合格式** | Reels（開箱過程）、Carousel（材質對比）、單圖（特寫） |
| **成功判準** | 觸及 > 200（非粉絲占比 > 40%）／按儲存數 > 10 |

#### 實際例子 3 個

1. **Reels**：「撕開包裝的那一刻」—— 鏡頭從信封到證書套的揭開過程，最後定格燙金名字特寫。
2. **Carousel**：「亞麻布 vs 磨砂珠光：4 個你需要知道嘅分別」—— 第 1 頁對比標題，2–4 頁各自說明特點（紋理／光澤／手感／風格），第 5 頁 CTA：DM 訂購。
3. **單圖貼文**：一個燙金名字「John & Mei Yan」的特寫，文案短一句話，不超過 50 字。

### 支柱二：註冊結婚流程與文件知識（25%）

| 項目 | 說明 |
|------|------|
| **定義** | 婚姻登記署預約、所需文件清單、常見錯誤、時間表 |
| **對應關鍵詞** | 婚姻登記署流程、申請結婚證書、註冊結婚費用、海外人士結婚 |
| **適合格式** | 兩平台均可：IG Carousel（步驟圖）、Threads 文字帖（QA 形式） |
| **成功判準** | 分享數 > 5／IG 觸及中搜索流量增長 |

#### 實際例子 3 個

1. **Carousel**：「去婚姻登記署登記，帶齊呢 5 樣嘢就夠」—— 第 1 頁標題，2–6 頁每頁一個文件清單，最後一頁 CTA：留言領取完整清單。
2. **Threads**：「你知唔知，結婚證書其實只有一張？之後嘅紀念冊係另外買㗎。」—— 引發討論，有人回覆詢問。
3. **Reels**：「登記當天做埋這件事，證書套就可以即刻寄出」—— 提醒在領證日當刻就下單，7–14 工作天後正好拿到成品。

### 支柱三：新人故事與交付實錄（20%）

| 項目 | 說明 |
|------|------|
| **定義** | 客人收貨照、真實交付故事、感謝留言截圖 |
| **對應關鍵詞** | 結婚證書套、客人實拍、證書套評價 |
| **適合格式** | IG Carousel（故事型）、單圖（實拍分享） |
| **成功判準** | 故事觸及 > 150／留言中有「定單」意圖字眼 |

#### 實際例子 3 個

1. **Carousel**：「Sarah & David 嘅故事：註冊咗喺灣仔，證書套已經喺屋企架住佢哋」—— 1–3 頁為客人實拍圖，4 頁為 MyO 款式對比，5 頁 CTA：你也想要嗎？
2. **單圖**：客人WhatsApp 截圖（文字 + 圖片打馬賽克），感謝語。
3. **Reels**：「從下單到收貨，7 日曆程記錄」—— 用時間軸展示製作過程。

### 支柱四：HK 婚禮文化 × 設計（15%）

| 項目 | 說明 |
|------|------|
| **定義** | 過大禮、敬茶、上頭、回門等習俗與證書套如何搭配 |

| **適合格式** | 純 Threads 文字帖、IG Stories |
| **成功判準** | 回覆數 > 3／分享數 > 5 |

#### 實際例子 3 個

1. **Threads**：「今日又幫一對新人燙印，新郎叫 Kevin，新娘叫小玲，燙銀配米色亞麻布，真係好襯。」—— 引發互動。

1. **Acquisition → Traffic Acquisition**：以 `utm_source` 為維度，查看 `instagram` / `threads` 帶來的會話數。
2. **Acquisition → Engagement**：查看社交媒體使用者的停留時間與頁面瀏覽數。
3. **Engagement → Paths**：查看社交媒體使用者在 site 上的導覽路徑（是否進入 blog）。

## 12. 風險與應對

### 風險 1：零影片素材

**現象**：repo 內無影片檔案，只可用照片代替。
**應對**：
- 用 Carousel（多張照片）代替 Reels，或將照片做成「動態 Carousel」（每張停留 1–2 秒）。
- 用文字動畫（Threads 的文字帖）代替 Reels，發揮 Threads 純文字優勢。
- 真實影片中：請客人提供手機拍攝的開箱影片，作為 UGC 素材。

### 風險 2：UGC 取得困難

**現象**：客人不願意拍照分享，或忘記分享。
**應對**：
- 包裹內放入感謝卡，明確說明如何分享（tagging + 折扣優惠）。
- 註冊後 1 週主動 follow-up， reminder 客人分享。
- 以「被 featured」作為誘因，而非金錢獎勵（更符合品牌調性）。

### 風險 3：IG 觸及波動

**現象**：某週觸及驟降，非粉絲占比低。
**應對**：
- 檢查 hashtag 是否被限流（避免使用过度通用的 hashtag）。
- 調整發佈時間（建議：週二、四、六 晚上 7–9 點，香港時間）。
- 增加 Reels 比例（Reels 的觸及池比 Feed 貼文大）。
- 使用 IG Stories 的 polls / questions 提升粉絲互動率。

### 風險 4：Threads 冷啟動無互動

**現象**：Threads 剛開通，互動數極低。
**應對**：
- 前 4 週以「知識輸出」為主，不以互動為目標，累積索引內容。
- 每則帖文結尾加提問句，引導回覆。
- 主動回覆他人 Threads（特別是婚禮相關話題），提升帳號能見度。
- 保持每日 2–3 則的穩定發佈，讓 Google 爬蟲有內容可以索引。

### 風險 5：品牌詞搜尋量低

**現象**：「MyO 專屬結婚證書套」搜尋量低，品牌認知不足。
**應對**：
- M3 階段密集輸出「結婚證書套」關鍵詞內容（支柱一拉到 40%）。
- 在 blog 文章中內鏈到產品頁（`index.html`，或 `v2.html` 這個改版首頁），強化 SEO。
- 與 KOL 協作，讓合作對象在貼文中使用品牌詞。
