# 教訓：把長 BPP 重複塞進每列欄位，令內容描述被樣板淹沒

> **日期**：2026-09-30
> **關聯**：MyO 內容庫遷移（27 列 `image_prompt` 欄位設計）
> **狀態**：已解決

---

### 問題

`image_prompt` 欄位採「完整 BPP + 場景描述」結構後，每列長度約 470 字，其中約 400 字是**完全相同的英文樣板**，實際描述只佔 20–30 字。

後果：

- 27 列看起來幾乎一樣，審閱時要逐字比對才能看出差異
- 真正重要的內容描述被推到最末端，容易被略過
- 使用者直接要求修正：「the image prompt should be more related to the content instead of the BPP」

第二輪修正（場景描述改中文）仍保留 BPP 前綴，長度只降到 350 字左右 —— 問題根源沒解決。

### 教訓

**重複的樣板應該集中管理一次，不該複製到每個資料列。**

判斷標準：如果一個值在所有列都相同，它就不屬於「每列的資料」，而屬於「全域規範」。放在資料列裡會造成三種損失：欄位膨脹、差異被淹沒、修改時要改 N 次。

**BPP 的作用是統一風格（該由品牌手冊管理），`image_prompt` 的作用是描述該則內容（必須逐篇寫）。** 兩者職責不同，混在同一欄會讓「決定張圖係咩」被「決定張圖靚唔靚」壓過去。

### 解法

**結構拆分：**

```
資料庫 image_prompt 欄位 = { 內容描述 20–60 字 }{（風格沿用品牌手冊 BPP：…）}
品牌手冊 BPP 章節 = 完整英文 prompt，集中一份
```

欄位長度 **470 字 → 107 字**。

**內容描述要對齊該則貼文的主題與格式**：

| 格式 | 描述重點 |
|---|---|
| Carousel | 分頁邏輯（2x2 排列、四步時間軸、三種排法並列） |
| Single | 單一主視覺 |
| Reels | 分鏡連續示意 |

**範例（修正後）：**

| # | 內容描述 |
|---|---|
| 02 | 四款證書套 2x2 排列，每款下方留白處標款式名與價錢：經典款亞麻布 HK$388、經典款磨砂珠光 HK$388、設計師款亞麻布 HK$588、設計師款磨砂珠光 HK$588 |
| 06 | 燙印工藝分解畫面：左為金箔卷與加熱壓頭特寫，中間為壓印瞬間的手部動作，右為完成品燙金名字特寫，三格連續示意 |
| 21 | 敬茶儀式場景：新人跪坐蒲團向長輩奉茶，側邊矮桌放著證書套，畫面著重感恩與尊重的傳統秩序 |

**同步更新規範頁**，否則文件與實際做法不一致，日後照 SOP 走會出錯 —— 在品牌手冊加一段：

> 生圖實際操作：將本頁 BPP 完整貼上 + 該列 `image_prompt` 內容描述 → 一併送入生圖工具。兩段都係必要，缺一不可。

### 預防

1. **設計資料庫欄位時先問：這個值每列都一樣嗎？** 一樣就移出去做全域規範
2. **把「樣板」與「資料」分開** —— 樣板進規範頁，資料進欄位
3. **欄位長度是健康指標** —— 若某欄位在 20 列以上長度都超過 200 字且高度重複，就是設計失衡訊號
4. **改完結構要同步更新 SOP 文件**，並把驗證腳本的檢查項從「BPP 逐字一致」改為「保留一行風格指引 + 已移除 BPP 全文」，否則會出現「改了資料但驗證腳本還在查舊結構」
